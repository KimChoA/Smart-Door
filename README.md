## 💡 프로젝트 배경

현관 보안에서는 방문자의 신원을 확인하는 것뿐 아니라  
**누가 접근했는지, 인증에 실패했는지, 어떤 상황에서 문이 열렸는지**를 함께 파악할 수 있어야 합니다.

본 프로젝트에서는 Raspberry Pi 4에 카메라와 센서를 연결하여  
**사용자 인증과 현관 상황 확인을 함께 수행하는 출입 보안 시스템**을 개발했습니다.

등록 사용자는 얼굴 인식으로 출입하고,  
비밀번호와 실내 스위치로도 도어락을 제어할 수 있도록 구성했습니다.

또한 미인증 접근과 비밀번호 연속 실패를 보안 이벤트로 기록하고,  
관리자가 웹에서 실시간 영상과 출입 기록을 확인할 수 있도록 구현했습니다.

# ✨ 주요 기능

## 👤 1. 얼굴 인식 기반 자동 출입

USB 웹캠으로 입력받은 영상에서 얼굴을 검출하고,  
등록된 사용자의 얼굴 특징과 비교하여 도어락을 자동으로 개방합니다.

- **YOLOv8** 기반 얼굴 영역 검출
- **YuNet**을 활용한 얼굴 정렬 정보 검출
- **SFace** 기반 얼굴 특징 추출
- 등록 사용자 특징과 비교하여 신원 판단
- 인증 성공 시 서보모터 도어락 개방
- 얼굴 인식 결과를 실시간 영상에 표시

단순히 얼굴이 있는지를 확인하는 것에서 나아가  
**등록 사용자 여부를 출입 제어와 연동**했습니다.

---

## 🔢 2. 비밀번호 인증

도어락 웹 화면에서 비밀번호를 입력하여  
문을 열 수 있도록 구현했습니다.

- 웹 기반 비밀번호 입력 화면
- 서버에서 비밀번호 검증
- **해시로 저장한 비밀번호**와 비교
- 인증 성공 시 도어락 개방
- 인증 성공·실패 결과 기록
- **3회 연속 실패 시 보안 이벤트와 사진 저장**

얼굴 인식 외에도 비밀번호를 이용할 수 있도록  
출입 인증 방식을 구성했습니다.

---

## 🚪 3. 서보모터 도어락 제어

여러 방식의 개방 요청을 하나의 도어락 제어 흐름으로 처리합니다.

| 개방 방식 | 동작 |
|---|---|
| **얼굴 인증** | 등록 사용자를 확인하면 자동 개방 |
| **비밀번호 인증** | 입력한 비밀번호가 일치하면 개방 |
| **실내 스위치** | 실내 버튼 입력으로 개방 |
| **관리자 원격 제어** | 관리자 웹에서 비밀번호 확인 후 개방 |

- 서보모터 잠금·개방 위치 제어
- 일정 시간 개방 후 잠금 위치로 복귀
- 도어락 작동 중 중복 개방 요청 제한
- 개방·잠금 명령 결과 기록
- 제어 오류 발생 시 상태 및 이벤트 전달

현재 코드의 개방 유지 시간은 **2초**이며,  
잠금 상태 표시는 실제 잠금 센서 측정값이 아닌 **서보 제어 명령 기준**입니다.

---

## 📏 4. 초음파 센서 기반 접근 감지

현관 앞 접근을 감지하면 얼굴 인증을 시작하고,  
미인증 상태가 지속되면 보안 경고를 발생시킵니다.

- **20cm 이내** 접근 감지
- 접근 시작 시 얼굴 인증 상태 초기화
- 등록 사용자 인증 여부 확인
- **미인증 접근이 10초 이상 지속되면 경고**
- 보안 이벤트와 현장 사진 저장
- 접근 종료 후 다음 인증을 위한 상태 초기화

접근 여부와 인증 상태를 함께 판단하여  
**등록 사용자 출입과 미인증 접근 상황을 구분**합니다.

---

## 🔁 5. 동일 접근 중 중복 인증·개방 방지

사용자가 카메라 앞에 머무르는 동안  
얼굴 인식 결과가 반복적으로 들어오더라도 도어락이 계속 작동하지 않도록 구성했습니다.

- 접근 시작·종료 상태 관리
- 해당 접근에서 인증을 처리했는지 확인
- 개방 요청 처리 여부 관리
- 도어락 작동 중 추가 요청 제한
- 접근 종료 확인 후 인증 상태 초기화

이를 통해 **얼굴 인식 반복 검출과 실제 도어락 작동을 구분하여 제어**했습니다.

---

## 🔔 6. 초인종 및 실시간 영상 팝업

초인종이 눌리면 부저로 알림음을 출력하고,  
관리자 웹에 방문 알림과 실시간 영상을 표시합니다.

- 초인종 버튼 입력 감지
- 부저 멜로디 재생
- 관리자 웹에 실시간 이벤트 전달
- **현관 영상 팝업 표시**
- 방문 상황을 CCTV로 확인

초인종 이벤트는 사진을 별도로 저장하지 않고  
**실시간 영상으로 방문자를 확인하는 방식**으로 구성했습니다.

---

## 🚦 7. RGB LED·부저 상태 표시

현관의 동작 상태를 RGB LED와 부저로 확인할 수 있도록 구현했습니다.

| 상태 | 표시 |
|---|---|
| **기본 대기** | 파란색 LED |
| **도어락 개방 또는 등록 사용자 인증** | 초록색 LED |
| **미인증 접근 경고** | 빨간색 LED 점멸 및 부저 |
| **보안 기능 비활성화** | LED 꺼짐 |

웹 화면을 확인하지 않아도  
**현장에서 대기·인증·경고 상태를 구분**할 수 있습니다.

---

## 🖥️ 8. 관리자 웹 대시보드

관리자가 현관 상태와 보안 기록을 한곳에서 확인할 수 있는  
**Flask 기반 관리자 웹**을 구현했습니다.

- 현재 도어락 및 보안 상태 확인
- 실시간 CCTV 영상 조회
- 비밀번호 확인 후 원격 도어락 개방
- 얼굴 인식 및 보안 기능 설정
- 출입 기록과 보안 이벤트 조회
- 보안 이벤트에 연결된 촬영 사진 확인
- 얼굴 등록·데이터 보강 페이지 연결

**Flask-SocketIO**를 통해 상태 변경과 보안 이벤트를 전달하여  
화면에서 최신 상황을 확인할 수 있도록 구성했습니다.

---

## 📷 9. 얼굴 등록 및 데이터 보강

별도 웹 페이지에서 신규 사용자의 얼굴을 등록하거나,  
기존 사용자의 얼굴 데이터를 추가할 수 있도록 구현했습니다.

- 신규 사용자 등록
- 기존 등록 사용자 선택
- 카메라로 얼굴 사진 수집
- 얼굴 특징 추출 및 저장
- 사용자 정보와 얼굴 특징 데이터 연결
- 기존 사용자 데이터 보강
- 등록 진행 상태 표시 및 취소

사용자 등록은 **YuNet·SFace로 얼굴 특징을 추출하고 저장하는 방식**이며,  
YOLOv8 모델을 사용자별로 재학습하는 방식은 아닙니다.

---

## 🗂️ 10. 출입·보안 기록 관리

인증 결과와 보안 상황을 **SQLite**에 저장하여  
관리자 웹에서 확인할 수 있도록 구성했습니다.

| 테이블 | 저장 내용 |
|---|---|
| `doorlock_settings` | 도어락 비밀번호 해시 및 설정 |
| `registered_users` | 등록 사용자와 얼굴 데이터 경로 |
| `access_logs` | 인증 방식, 성공 여부, 출입 관련 기록 |
| `security_events` | 보안 이벤트, 사진 경로, 연관 출입 기록 |

비밀번호 인증 실패와 보안 사진처럼 서로 관련된 정보를 연결하여  
**이벤트 발생 상황을 기록과 함께 확인**할 수 있도록 했습니다.

# 🔄 시스템 동작 흐름

### 얼굴 인식 출입

1. 초음파 센서가 현관 접근을 감지합니다.
2. 카메라 영상에서 얼굴을 검출합니다.
3. 얼굴 특징을 추출하여 등록 사용자와 비교합니다.
4. 인증에 성공하면 도어락을 개방하고 기록을 저장합니다.
5. 일정 시간 후 잠금 위치로 복귀합니다.
6. 접근 종료를 확인하면 다음 인증을 준비합니다.

### 보안 경고

1. 현관 앞에서 미인증 접근이 지속됩니다.
2. 설정된 감지 시간인 10초가 경과합니다.
3. RGB LED를 빨간색으로 점멸하고 부저를 작동합니다.
4. 현장 사진과 보안 이벤트를 저장합니다.
5. 관리자 웹에 경고를 전달합니다.

### 초인종 알림

1. 방문자가 초인종을 누릅니다.
2. 부저 알림음이 재생됩니다.
3. 관리자 웹으로 초인종 이벤트가 전달됩니다.
4. 실시간 현관 영상 팝업으로 방문자를 확인합니다.

# 🛠️ 구현 시 고려한 점

## 1. 반복 검출과 중복 개방 제어

카메라는 같은 사용자의 얼굴을 연속해서 검출합니다.  
이를 매번 개방 명령으로 처리하지 않도록 **접근 상태와 개방 처리 상태를 함께 관리**했습니다.

## 2. 인증 상태와 보안 경고 연동

근접 상태만으로 경고를 발생시키면 등록 사용자에게도 경고가 발생할 수 있습니다.  
**접근 시간과 사용자 인증 여부를 함께 확인**하여 미인증 상황에 대해 경고하도록 구성했습니다.

## 3. 도어락 제어와 부가 기능 분리

도어락 작동 중 DB 기록이나 상태 전송에 오류가 발생하더라도  
**잠금 위치로 복귀하는 작업을 우선 시도**하도록 예외 처리를 구성했습니다.

## 4. 상태와 기록의 실시간 전달

장치에서 발생한 변화를 관리자 화면에 전달하기 위해  
**Flask-SocketIO 이벤트를 활용하여 상태·출입 기록·보안 알림을 연동**했습니다.

# 🎯 핵심 구현 성과

- **Raspberry Pi 4 기반 영상 처리·웹 서버·GPIO 제어 통합**
- **YOLOv8·YuNet·SFace를 활용한 얼굴 인증**
- **얼굴·비밀번호·스위치·관리자 요청을 연결한 도어락 제어**
- **동일 접근 중 반복 인증 및 중복 개방 제한**
- **초음파 센서와 인증 상태를 결합한 미인증 접근 경고**
- **초인종 이벤트와 실시간 CCTV 팝업 연동**
- **SQLite 기반 사용자·출입·보안 기록 관리**

카메라로 사용자를 인식하는 기능을 실제 장치 동작과 연결하고,  
그 결과를 **관리자 웹과 데이터베이스에서 함께 확인할 수 있는 시스템**으로 구현했습니다.
